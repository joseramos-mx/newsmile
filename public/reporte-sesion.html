02 Responsive móvil — Sección Servicios Arreglado

Problema raíz

El grid de ServiceRow usaba columnas fijas (3.5rem 1fr clamp(14rem,28%,22rem) auto) que sumaban ~400px, dejando 0px para el título en pantallas de 375px. Además la sección no tenía padding horizontal y usaba overflow: visible + márgenes negativos → scroll horizontal en móvil.

Solución aplicada

  • Layout de 3 columnas para móvil con grid-template-areas (número + título + flecha arriba, descripción debajo)
  • Media query separada para desktop (≥768px) que conserva las 4 columnas y la extensión lateral del hover
  • Padding horizontal añadido al contenedor interno: clamp(1.25rem, 4vw, 3rem)
  • overflow: hidden en la sección para contener el marquee

03 Fix canonical SEO — vercel.app → newsmileld.com Desplegado

Causa raíz identificada

El sitio declaraba a Google que su URL canónica era newsmileld.vercel.app (canonical tag, og:url, og:image, JSON-LD). Google obedecía el canonical e indexaba la versión Vercel en vez del dominio final.

SITE_URL centralizado

Creado app/lib/site.ts con la constante SITE_URL = "https://newsmileld.com" (más teléfono, email, dirección). Antes el dominio estaba hardcodeado en 4 archivos distintos.

Archivos actualizados

  • app/layout.tsx — metadataBase, alternates.canonical, og:url, twitter, todo el JSON-LD
  • app/robots.ts — host y sitemap apuntan a newsmileld.com
  • app/sitemap.ts — todas las URLs con dominio canónico

Redirect 308 en next.config.ts

Cualquier request a newsmileld.vercel.app/* rebota a newsmileld.com/* con un 308 permanente. Cinturón y tirantes para que Google consolide las señales en el dominio canónico.
